## 已实现

- 创建和编辑项目名称、预期结果、可选目标日期、低/普通/高优先级。
- 每行一条批量添加项目任务，默认没有安排日期。
- 项目任务加入今日不复制任务；已有安排可直接查看，已完成任务跳到实际完成日期。
- 今日修改标题、改期或完成后，项目列表读取同一任务的最新状态。
- 收件箱和今日详情中的临时任务可归入已有项目，保留原任务 ID、安排和历史。
- SQLite 迁移 0005 增加项目及项目历史；项目归属写入校验同一 owner，业务变化与历史/outbox 原子提交，支持版本校验和幂等重试。

项目中尚未安排的任务不再显示在收件箱。优先级是项目字段，不代表任务重要度。现有 tasks.source 字段保留旧版兼容值，页面按 project_id 判断当前项目归属，创建事件区分项目任务与临时事项。

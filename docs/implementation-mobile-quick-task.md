# 手机快速添加任务

2026-10-18，按用户提供的 Todo 清单截图简化手机录入。任务清单、日历和项目内的“＋”现在优先打开底部快速添加面板。

## 使用方式

1. 点“＋”，标题自动聚焦，可直接输入。
2. 只填标题，点右上角“添加”，或用键盘回车提交。
3. 日期可直接选今天、明天、自选日期或没有日期。默认沿用当前查看日，今天页面默认今天；没有日期的任务进入收件箱。
4. 描述可选。项目、父任务、优先级等通过“更多选项”进入原完整编辑器，已填标题、描述和日期保留。

添加按钮随面板保持在上方，面板适配软键盘后的可用高度。保存后显示任务去向，重复提交仍由原有保存锁和幂等操作保障；已有任务的完整编辑入口保持可用。

## 验证与安装包

TypeScript 检查、前端构建与 Android APK 构建通过。已覆盖安装到 Android 17 模拟器，使用独立云端账号配合真实 Windows 桌面程序验证：

- 标题自动聚焦、空标题不能提交；软键盘打开后添加按钮在可视区域，无横向溢出。
- 仅填标题创建任务；明天、没有日期和自选日期在桌面原生存储中保留正确日期。
- 回车仅创建一条任务。
- 更多选项保留标题、描述和日期，可在完整编辑器保存。
- 任务双向同步、完成状态回传与双端进程重启后数据保留。
- 测试后退出验收账号，手机原本机任务列表与测试前一致。

运行方式：`PRAXIS_QUICK_TASK_SMOKE=1 node scripts/ecs-dual-client-smoke.mjs`（PowerShell 先设置同名环境变量）。脚本临时调整并恢复模拟器软键盘偏好，不包含密码或令牌记录。

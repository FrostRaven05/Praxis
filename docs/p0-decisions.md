## 平台与同步

沿用已记录 Windows + Android 第一组验证设备，当前 P0 交付 Windows 本地；Android 真机、iOS 不在本轮完成声明内。沿用 TECHNOLOGY.md 的 Fastify + PostgreSQL + Supabase Auth 技术方向，本轮不开通云服务、不部署、不发送数据。部署区域、账号资源、预算与是否要求端到端加密仍在 T23 实施前由实际环境确认，不能以本地 outbox 代替同步。

## 开工条件与实现缺口

1. 完成 T25/T26：真实授权工作空间、两台设备身份、服务端版本与增量协议、持久化冲突及解决命令。取得测试环境与独立服务备份恢复权限，凭据仅通过本机安全配置提供。
2. 定义墓碑保留、设备确认水位、长期离线设备重新建基线及服务端恢复代次。用户回收窗口和同步墓碑清理必须分离；时间戳不能替代版本/游标判断。
3. 在服务端保存 command ID、请求身份与内容校验以及已提交结果；提交与幂等记录原子化。客户端只在可靠确认后推进已确认状态，崩溃和响应丢失可续传。
4. 为“远端删除、本地待发编辑”保存可取回的编辑内容与冲突，不静默丢弃，也不自动创建或恢复原对象。状态、归属、关联组需重新校验。
5. 实现游标失效恢复：先持久保存未确认操作及所需本地内容；获取同一服务端版本的一致快照；校验版本、数量和引用；在受保护的切换过程重放有效操作，删除目标转冲突。失败可返回旧状态，禁止清库重建。
6. 拉取与本地编辑并发时更新已确认基线，保留或重放待发修改；未保存输入亦不能被远端刷新覆盖。提供真实同步状态、最近成功时间、可重试错误和重新授权续传。
7. 制定服务端备份恢复规程，涵盖业务表、墓碑、幂等记录、增量日志、冲突及身份授权；明确恢复点后曾获确认的操作如何恢复或暴露为可处理差异。

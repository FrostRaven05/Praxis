# D08 追踪项目与紧凑布局

根据用户截图修改项目页：删除顶部面包屑、介绍标题及说明，将新建和筛选合并成紧凑工具栏，项目目录缩窄，内容区使用剩余宽度。左侧原说明区域改为追踪项目列表。

“重点项目”统一显示为“追踪项目”，底层沿用 focused 字段，因此已有标记直接保留。追踪入口显示名称、项目状态与当前选择；归档且仍追踪的项目也可打开。取消追踪后入口即时移除。快捷导航从今日、收件箱及项目页均可进入，清理项目表单和批量任务草稿，并回到主区顶部；项目保存中禁止快捷切换。

同时修复错误日志并发写入：侧栏与主区同时读取失败时，诊断行通过互斥锁和整行写入保持完整。

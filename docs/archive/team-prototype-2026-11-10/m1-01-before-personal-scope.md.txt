# M1 01 共享项目与资源授权实施记录

日期：2026-11-10  
结果：M1-01 完成  
依据：[开发计划](../mvp-development-plan-2026-11-09.md)与[M0 共享资源规格](../m0/specification.md)

本轮建立服务端共享项目、成员与任务身份模型，接通真实账号会话和资源级授权。原有个人实体、账号、桌面与 Android 数据路径继续保留。邀请加入、历史资料迁移、完整任务命令、两端共享同步和新界面仍按后续任务推进。

## 已交付能力

| 能力 | 当前行为 |
| --- | --- |
| 项目创建 | 名称校验、目标和目标日期、合法 IANA 时区、初始版本 1；事务内自动建立唯一创建者成员 |
| 真实账号 | v2 只接受注册账号会话，配置式旧设备令牌继续用于 v1，不获得共享权限 |
| 成员授权 | 当前有效且未禁用的成员可读项目和创建任务，非成员统一拒绝；未存在与不可访问项目的查询响应一致 |
| 任务身份 | 作用域为项目与任务 ID；createdBy 来自认证操作者，assigneeId 默认当前用户或当前成员，初始状态 todo |
| 参数边界 | 不接受自报创建者、操作者、经验领取人或 approved；校验设备、项目路径、访问代数及日期 |
| 数据约束 | 单一且不可变创建者，成员与账号外键，当前有效负责人，项目内任务唯一；不同项目可保留同任务 ID |
| 原子写入 | 项目、成员、任务、事件和回执保持事务边界；故障时不留下部分任务或假成功 |
| 重试与核对 | 相同操作者和操作标识防重，规范化内容变化时拒绝，支持同账号跨设备重试；回执读取及重放前重新授权 |

项目时区在创建时校验并固定保存；客户端从账户设置自动提供时区的入口属于 M2。任务的可选备注和截止可以省略，服务端归一化后保存；日期级截止必须使用项目时区。原有瞬时时间和个人计划数据不作转换。

## 本轮开放的接口

| 接口 | 支持范围 |
| --- | --- |
| POST /v2/projects | 使用 project.create 信封创建项目及创建者成员 |
| GET /v2/projects/:projectId/snapshot | 当前授权下的项目、有效成员、未删除任务和读取时间 |
| POST /v2/projects/:projectId/commands | 本轮仅支持 task.create 批量新增待办任务 |
| GET /v2/commands/:operationId | 当前用户发起且仍有项目权限的业务回执 |

新增的服务端表为 shared_project_schema、shared_projects、project_members、project_tasks、shared_project_events 和 shared_command_receipts。采用独立共享表，原 v1 实体和变更流不会自动包含这些数据；增量变化读取及客户端缓存接入属于 M1-04。

源码分为[协议与参数](../../apps/api/src/project-contract.ts)、[存储与业务授权](../../apps/api/src/project-store.ts)和[路由](../../apps/api/src/project-routes.ts)。现有 [server.ts](../../apps/api/src/server.ts) 仅增加模块装配、v2 认证分流与领域错误处理，没有替换既有个人服务。新响应类型通过编译期测试与 M0 冻结契约对齐。

## 保留范围与下一步

本轮未运行线上部署、真实用户资料迁移、模型请求或客户端界面验收。现有界面继续使用原有个人路径，尚未显示新的共享数据。既有未提交工作保持保留。

M1-03 的任务编辑、重新分配、状态、删除恢复和完成事实尚未交付；现有基础创建回执不等于全部统一命令完成。项目成员邀请、撤权转交、共享同步和 AI 协作确认也保持待执行状态。

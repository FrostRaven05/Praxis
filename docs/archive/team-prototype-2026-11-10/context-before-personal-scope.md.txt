# Praxis 任务与项目领域

Praxis 将有边界的目标组织为项目，通过有负责人、可完成的任务推进，并为个人提供行动反馈。以下术语区分当前个人工作台与聚焦版协作需求。

## Language

**项目 Project**：围绕一个预期成果组织的任务集合。任务全部完成与项目成果验收是不同的事实。

**任务 Task**：由一位负责人承担、具有可观察完成结果的行动。它可属于一个项目，也可作为个人独立任务。
_Avoid_：每日安排、记录

**项目创建者 Project Creator**：建立项目并管理其成员的人。首版每个项目只有一位创建者。
_Avoid_：负责人、成员管理员

**任务创建人 Task Creator**：最初建立任务的人，不随任务转交而改变。
_Avoid_：负责人

**负责人 Assignee**：当前承担任务的人；项目任务的负责人必须是项目当前成员。
_Avoid_：创建人、操作者、所有者

**操作者 Actor**：实际发起一次业务变更的人。操作者可以与任务负责人不同。

**项目成员 Project Member**：当前有权参与项目的用户，包含项目创建者。非成员只能在有效邀请下预览加入所需的项目名称。

**个人资料 Personal Data**：仅归属某位用户的任务、记录或设置。与项目存在关联不代表已向项目成员共享。

**项目资料 Project Data**：明确纳入项目协作范围、由当前成员按权限共同访问的内容。

**截止日期 Due Date**：任务应完成的最后一个项目当地自然日。它与用户打算在哪天执行任务的每日安排分开。
_Avoid_：计划日期、目标日期

**截止时刻 Due Instant**：旧任务保存的一个确定时间点，继续保留其原显示时区与精度。

**每日安排 Daily Arrangement**：用户决定在某日推进某项任务的安排。未安排的任务仍然可以是个人待办。
_Avoid_：截止日期、任务副本

**任务完成比例 Task Completion Ratio**：按约定任务口径计算的已完成数量与总数之比。
_Avoid_：成果验收比例、预计完工进度

**行动包 Work Package**：旧修炼规则中由一个根任务及其子步骤组成的计分单元。它不等于新版经验的一项任务贡献。

**任务经验 Task XP**：新版按当前有效已完成任务计入的个人贡献，每项任务同时最多一份，归完成时的负责人。
_Avoid_：旧修为、团队绩效

**经验领取人 XP Recipient**：一次有效任务完成时取得经验的人。任务转交不会直接转移该次完成的历史经验。

**行动草稿 Action Draft**：尚未被用户确认的任务建议。草稿不属于正式待办、项目统计或经验来源。

**采用 Adoption**：用户检查具体草稿后，将其确认转为正式任务的业务动作。
_Avoid_：生成、任务完成

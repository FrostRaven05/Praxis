# 设置与独立登录页改版

日期：2026-11-13（Asia/Hong_Kong）。按本轮用户要求，移除设置页的“本地备份”展示卡片，将账号操作移出设置表单，改为独立登录页，并在桌面左下角常驻账号入口。

- 独立登录页使用邮箱、密码、显示/隐藏密码、主登录按钮与注册切换；注册保留昵称和原密码规则，高级连接设置默认折叠。
- 登录页有“返回应用”，可继续使用本机内容；它是独立页面，不是弹窗。已登录时账号页显示昵称、邮箱及退出入口，过期时可重新登录。
- 桌面左下角显示账号头像、昵称、邮箱；未登录时显示“未登录 / 登录以同步”。编辑未完成或保存期间沿用原导航保护。
- 手机“我的”页账号入口使用同一独立页面；系统返回优先返回应用，认证或工作空间切换过程中防止误退出。
- 设置页仅保留主题和归档项目。本轮不删除备份文件、自动备份或底层恢复能力，不改账号、同步协议或数据库结构。

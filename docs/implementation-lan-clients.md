# Windows / Android 局域网自动同步

2026-10-11，基准提交 `09cb851`。本文保留第一轮 LAN v1 **收集项原文和删除墓碑**接入记录。同日后续已实现任务、项目、安排、记录、习惯等全域协议，最新范围与验收见 [全域局域网同步](implementation-full-sync.md)。下文测试数量和限制对应第一轮实现；云账号登录仍未交付。

## 已实现

- Windows Rust 原生循环：应用运行期间，每轮结束 5 秒后再次发送和拉取；Android：前台每 5 秒，以及联网/恢复前台时触发。手机被系统停止期间不承诺后台同步，重启后自动继续。
- 两端先保存本机；发现差异后持久化冻结命令，重试使用相同 operationId 和原参数。服务端版本与本机版本分开，确认上传不会覆盖发送期间的新编辑。
- 每用户增量游标；每页 25 条，实体合并、同步历史和游标同事务提交。拉取校验类型、UUID、日期、长度及连续游标，异常页不推进游标。
- 未发送的本机修改不会被拉取覆盖。冲突保留双方文本，不阻塞独立收集项。可明确接受服务端，或将本机文字保留为新的收集项后接受远端；选择本身有版本校验、稳定操作 ID 和已提交回执。
- 桌面同步状态、最近成功、待发/冲突数量及原文活动历史；手机同步状态、最近成功与冲突展开查看。编辑草稿不随后台拉取丢失。
- 桌面 migration 0020；手机 SQLite v4 附加迁移。没有改写已安装版本迁移或清空本机库。

## 配对和隔离

在仓库根目录 PowerShell 执行：

```powershell
./scripts/pair-lan-clients.ps1
```

默认使用 `.tools/lan/clients.json` 的两个开发设备、当前 Windows 用户及 `emulator-5554`。桌面位置为 `%APPDATA%/com.praxis.desktop/lan-sync.dpapi`：使用 DPAPI CurrentUser 加密，Rust 原生解密，令牌不返回 React。可用 `-DesktopOnly` 或 `-MobileOnly` 单独配置；桌面验收可指定 `-DesktopDataDirectory`，手机可指定 `-AndroidSerial`。

Android 配对由 adb `run-as` 直接流入 App 私有 `files/lan-provision.json`，没有经过共享存储；仅 debug 接受此文件。启动后由 Android Keystore AES-GCM 加密保存到私有 SharedPreferences，再删除临时明文。发布版配对界面尚未实现。

两端只信任配对 CA，保留主机名验证并禁止重定向，不安装系统全局证书、不放宽 cleartext/CSP、不把令牌写进 APK 或 Web bundle。手机工作空间绑定 `local`，切换到导入空间后停止其同步；端点/owner/device 不匹配会拒绝沿用已有绑定。当前没有账号切换或迁移向导。

## 验证

- TypeScript 检查、前端和调试 APK 构建通过。
- 全仓 Vitest **86 项**通过，其中 5 项手机 LAN 存储测试；Rust **89 项**通过，其中 3 项桌面 LAN 存储测试。
- 真实 Windows WebView2 App 与 Android 17 模拟器：桌面原文创建自动出现在手机；手机编辑自动更新桌面。
- 手机禁用 Wi-Fi/数据后编辑、强制停止/重启，原文仍在；恢复网络后自动上传且只有一个收集项。
- 手机离线编辑与桌面在线编辑产生并发冲突，界面同时保留两份原文；选择保留本机副本后，两份内容继续同步。
- 后端停止期间桌面仍可保存；恢复服务后自动继续同步。脚本还覆盖桌面在停机期间重启后的恢复。
- 测试写入来自 App UI，没有用直接后端写入冒充双端接入；原有手机记录保持。主验收桌面使用独立数据目录，完成后正常桌面目录也配置配对。
- 证据位于 `docs/evidence/lan-dual-sync/`，脚本 `scripts/lan-dual-sync.mjs` 和 `scripts/lan-sync-recovery.mjs`。调试连接为桌面 9222、手机 9223；脚本说明列出了前置启动与转发条件。

## 审查修复

Spec 发现 Android 插件 `run()` 默认自带事务，与显式事务嵌套；已统一传 `false`，冲突两项标记也改为原子提交。测试适配器现在模拟这一原生默认行为，实际 APK 复验通过。

Standards 发现远端删除会隐藏桌面编辑草稿、同步缺少可读历史，以及冲突决策未知提交无法重试；已加入编辑期间刷新保护、事务内前后值历史和幂等决策回执。明确版本拒绝会释放旧决策，允许重新选择；未知提交仍保留原请求重试。

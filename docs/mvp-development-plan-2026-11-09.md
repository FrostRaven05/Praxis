# Praxis 个人管理开发计划

更新：2026-11-12  
需求基线：[个人版 PRD](prd-mvp-v0.1.md)  
范围：整个项目只做个人管理  
状态：共18项个人任务全部完成本轮实施与验收；Android按用户选择使用实际隔离模拟器，实体手机及系统输入法候选操作未覆盖

本计划替代此前团队方向的未完成任务。原 M0 的时间、备份、账号隔离和规则验证可复用；M1-01 团队服务切片已撤出生产路径并归档。旧 M1-05 的共享项目迁移不再执行。P0至P4已完成，最终结果与验收范围见[P4交付记录](p4/personal-mvp-acceptance-2026-11-12.md)。

同一账号 Windows 与 Android 同步保留。任务默认属于自己，项目只是个人任务组织方式；不增加成员、邀请、分派或团队权限，也不将这些能力列为后续候选。

| P1 核心体验           | 个人待办、项目列表和详情、行内操作、手机适配 | 五个个人场景连贯可用                               |

## P0 个人范围与兼容

- [x] **P0-01 固定个人产品边界。**更新 PRD、当前计划和术语；撤下共享服务集成，归档团队源码和旧方案；新增个人范围回归测试。验收：无团队接口和新建成员表逻辑，旧内容保留，现有个人账号和同账号同步正常。
- [x] **P0-02 完成个人数据兼容清单。**已盘点个人任务、项目、旧树形/状态、日期、修炼、AI及同步内容，补充独立的个人合成样本、双端结构与版本映射；新增2项桌面和3项手机存储测试，验证升级、任务身份、版本、防重、整库备份恢复与队列保留。详见[兼容清单](p0/personal-data-compatibility.md)和[实施验证](p0/implementation-p0-02.md)。依赖：P0-01。P-AC03、P-AC07、P-AC14的数据部分有证据，完整界面和真机验收仍在P4。
- [x] **P0-03 固定个人查询和变更边界。**已实现共同个人查询与双端变更适配，复用原业务事务，统一列表/详情/待办/统计、typed日期与旧状态投影，保留账号、版本、稳定操作与完成事实。新增10项TypeScript和3项原生测试，验证项目变化不复制任务、待办无需加入今日、旧时间和扩展字段保留。详见[接口约定](p0/personal-task-interface.md)和[实施验证](p0/implementation-p0-03.md)。依赖：P0-02。新默认页面与交互按P1继续实现。

## P1 核心体验

- [x] **P1-01 实现个人待办首页。**桌面与手机默认打开共同首页，覆盖全部个人项目与独立任务，分逾期、今天、之后和无日期，空组隐藏、已完成折叠；可打开原任务/项目并快捷完成、重开，保留旧每日安排与其他入口。类型检查、285项TypeScript、11项原生兼容及14组双端界面检查通过，构建通过。详见[实施验证](p1/implementation-p1-01.md)。依赖：P0-03。P-AC03/P-AC08已有本阶段证据，P-AC13存储回归通过，完整真机同步仍在P4。
- [x] **P1-02 精简项目创建和列表。**双端共用三字段简表单，名称必填、目标与目标日期可选，创建成功进入详情；共同列表按项目最近更新时间排列，显示完成数量、比例与任务逾期，空项目和旧树形口径明确。保留旧字段与高级入口，稳定操作防止未知结果重试重复创建，明确拒绝保留输入。类型检查、294项TypeScript、180项原生完整回归、16组项目及14组待办界面检查、客户端和API构建通过。详见[实施验证](p1/implementation-p1-02.md)。依赖：P0-03。P-AC01及P-AC06的创建、列表与重开统计已有本阶段证据；删除恢复和完整设备验收仍按P1-04、P4执行。
- [x] **P1-03 完成行内任务闭环。**双端首页与项目详情共用行内录入和编辑，支持回车连续添加、中文组词保护、待办/进行中/已完成、说明与可选截止，不显示负责人；旧精确时刻仅在明确修改时转换，旧层级与高级入口保留。稳定ID与原回执防重，未知结果冻结重试，版本冲突保留输入且不覆盖新编辑，编辑时延后同步和时间分组变化。301项TypeScript、182项原生完整回归、28组行内及30组既有页面检查、类型检查与构建通过。详见[实施验证](p1/implementation-p1-03.md)。依赖：P1-01、P1-02。P-AC02的客户端事件保护及P-AC04的三态、版本保护已有本阶段证据；撤销/恢复在P1-04，实际双端输入法和网络验收在P4。
- [x] **P1-04 统一进度和恢复反馈。**完成空项目、全完成、重开、软删除/恢复与10秒撤销；精确版本检查拒绝覆盖新编辑，未知结果使用原操作ID重试，失败保留输入与完成事实。旧层级保留兼容统计和原回收站。新增5项TypeScript与2项原生测试，整合页面及实际Windows删除撤销验证通过。详见[实施记录](p1/implementation-p1-04.md)。依赖：P1-03。P-AC04、P-AC05、P-AC06通过本轮验收。
- [x] **P1-05 完成手机与桌面一致体验。**主导航收敛为待办/项目，三个核心页面、桌面任务侧栏和手机全屏面板接入，保留保存/同步状态及高级个人功能次级入口。86组浏览器及7组实际双端旅程通过。详见[实施记录](p1/implementation-p1-05.md)。依赖：P1-01至P1-04。P-AC13至P-AC15结果及设备边界见P4。

## P2 成长修炼

- [x] **P2-01 实现个人任务经验。**从原持久任务事实按scope与任务ID投影有效贡献，每项10 XP，完成/撤销/删除/恢复防重，移动项目不重计，不新增第二份计分账本或迁移。规则与真实SQLite、实际双端10 XP/删除撤销均验证。依赖：P0-03、P1-04。P-AC05、P-AC09通过，见[P2记录](p2/implementation-personal-growth.md)。
- [x] **P2-02 保留旧修炼与奖励历史。**新XP与旧行动包修为独立，未知完成时刻不制造今日事实；桌面原修炼与手机原奖励记录入口保留，旧数据和队列在可重复备份恢复测试中不变。依赖：P2-01、P0-02。详见P2记录。
- [x] **P2-03 加入轻量游戏化。**首页经验条、等级、约700ms非阻塞文字/升级反馈，隐藏后可恢复，支持本设备按账号偏好和系统减少动效。成长相关11项TypeScript、独立组件12组及完整App整合检查通过。依赖：P2-02、P1-05。P-AC09、P-AC15通过，见P2记录与P4。

## P3 行动助手

- [x] **P3-01 固定个人上下文与任务草稿。**读取可信个人scope、项目/任务版本与原上下文，生成平铺标题、可选说明/截止，不配置成员、依赖、估时和奖励。未确认只保留设备草稿；超过100项的单项目明确限制新AI拆解。真实模型输出及原兼容协议通过。依赖：P0-03、P1-02。详见[P3记录](p3/implementation-p3-01-04.md)。
- [x] **P3-02 完成一次确认与个人采用。**可编辑与删减，持久稳定任务/操作ID，原事务与回执防重，仅生成设备采用。实际Windows真实草稿确认一项后，Android收到同一任务及用户编辑的说明/日期。依赖：P3-01。P-AC10、P-AC12通过，见P3/P4记录。
- [x] **P3-03 实现只读进展与下一步。**项目和待办两处入口，程序提供真实统计、最多三项现有任务建议及来源时间，AI解释单独标识；实际Android真实模型调用前后任务ID/版本不变。依赖：P3-01、P1-01。P-AC11通过。
- [x] **P3-04 完善失败与恢复。**生成、待确认、采用、停止和终态可见，有限超时/查询，未知先核对原回执；缓存按scope隔离，拒绝篡改命令与异步scope切换，保留旧草稿/来源及手动路径。AI组合76项TypeScript、6项原生和完整页面回归通过。依赖：P3-02、P3-03。P-AC12、P-AC14见P3/P4证据。

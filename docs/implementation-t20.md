# T20：本地习惯记录和周统计

新增每日、指定星期和每周 N 次习惯。创建表单保存开始日期、触发情境、正常版本、最低版本、说明及项目上下文。习惯有独立生命周期，不创建任务，也不会因项目结束自动结束。

`HabitsView` 提供名称及说明搜索、日期选择、完成、跳过理由、撤销和周统计；今日通过 `compact` 模式仅展示适用习惯。每周 N 次没有预先指定执行日，达标后折叠，可展开继续记录额外完成。

周一为周起点；每日/指定星期显示适用日期分母，每周次数显示不同完成日期数与固定目标，跳过单列。剩余日期为所选周内从工作空间实际今天起、适用且尚未完成/跳过的日期。新建的非完整周不评价完整周达标，当前周显示进行中。

## 数据与一致性

迁移 `0014_habits.sql` 增加 `habits`、`habit_schedules`、`habit_entries`、`habit_events`。规则有效区间为左闭右开，数据库触发器禁止同一天出现重叠规则。初始版本为 0；暂停与规则变更入口由 T21 实现。

每习惯和日期的复合主键保证一条当前记录，更新必须携带期望版本。完成、跳过、撤销和同步发送队列同事务提交；命令 ID 可幂等重试。撤销将当前状态置空，保留递增版本和事件中的原记录。记录保存当地日期、IANA 时区、实际时刻和规则版本，工作空间时区改变不会重新解释历史日期。过期界面的时区与版本写入会拒绝并要求刷新。

服务接口为 `habit_command(command)` 和 `habit_snapshot(date)`。全量视图和今日视图由主集成接入；跨设备冲突界面属于后续同步工单，不将本地版本冲突检查宣称为跨端同步。

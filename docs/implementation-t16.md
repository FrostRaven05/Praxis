# T16 — 离线搜索与基础工作视图

2026-10-09，Windows 本地实现；对应 REC-005、VIEW-001–003，AT-20 仅本地部分。

## 行为

- 同一搜索入口覆盖任务、项目、记录和习惯的标题、正文/上下文。文字按字面匹配，支持中文与大小写无关的英文；可限制类型、项目和状态。记录项目范围同时包含直接项目链接与任务所属项目。
- 已删除任务、项目、记录不参与普通搜索。归档项目和归档项目任务默认排除，可显式包含。习惯搜索包含提示情境、正常/最低版本和备注，不创建任务。
- 任务条件编辑器支持项目、状态、标签、P1–P4、预计分钟、计划/截止/跟进日期、主下一步，以及供预设使用的独立任务/项目活跃/未阻塞条件。最多三个 OR 组，每组最多十二个 AND 条件。固定字段、操作符与类型验证，无代码表达式、动态 SQL 或 eval。
- 日期条件按当前工作空间时区解释，日期型值保持原日期；今天/本周条件在每次查询时计算，本周从周一开始。缺失预计时长不当作零分钟；缺失日期不会匹配到期条件。
- 五个预设：未安排独立任务、集中推进、零碎处理、等待跟进、本周期限。集中推进要求活跃项目、主下一步、todo/doing、无未完成依赖；等待跟进仅返回已到跟进日期的等待事项。15 分钟阈值可改。
- 保存名称、全部筛选、排序、分组与侧栏关注；保存视图只接受任务实体。项目/标签引用稳定 ID，重命名后筛选仍有效；缺失引用在结果区域警告，不静默移除筛选条件。
- 结果可查看完整正文，任务/项目可打开编辑入口。保存出错保留输入；并发版本过期明确提示重新载入或另存副本；删除视图不删除任务。

## 数据与集成

迁移 `0016_views.sql` 新建 `saved_views`，包含稳定 ID、owner、entity_type、AST 版本、完整 query JSON、关注、并发版本、创建/更新/删除时刻。删除保留墓碑字段。新增表自动包含于现有完整 SQLite 备份；同步协议仍留给 T28。

`Store::view_command` 在同一事务写视图、`content_events`、`sync_outbox`；同 operation ID 同负载重试不重复。旧版本修改及无效 AST 回滚整个事务。查询不写业务数据。

公开命令：`view_snapshot`、`view_query({query})`、`view_command({command})`。界面：`SearchViews({initialViewId,onChanged})`；侧栏：`FollowedViews({onOpen,disabled,revision})`，由主界面保存选择的视图 ID，避免首次挂载时丢失导航。

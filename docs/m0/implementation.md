## 兼容决策

1. owner、创建者、创建人、负责人、操作者和经验领取人分开建模，个人同 ID 资料不因协作而合并。
2. 新平铺三态与旧 waiting、blocked、cancelled 及层级数据分开投影，不静默改写旧状态或双计父子。
3. 日期级截止、旧瞬时时间和每日安排各自保留；项目自然日使用其固定时区判断。
4. 新版任务 XP 独立于旧修为；旧奖励历史保留，未知完成时间不伪造成今天，删除与重开按新版贡献回退。
5. 新共享 AI 确认和回执由服务端持有；旧本地回执继续可读，不能充当跨设备采用锁。

## 本轮边界与下一步

新 TypeScript 模块仅用于契约和参考规则验证，没有从现有 application/index.ts 导出，也没有接入 UI、路由、数据库或同步队列。共享项目、成员邀请、正式任务负责人、XP 账本和 AI v2 执行仍属于后续任务。

合成成员与过期确认用于冻结行为预期，不代表共享授权已实现。M0 的数据库恢复与规则测试也不替代 Windows、Android、双账号完整旅程和真实模型验收。

下一项为 M1-01：按照本次作用域协议建立共享项目和资源授权，再按计划推进旧项目映射和统一任务命令。

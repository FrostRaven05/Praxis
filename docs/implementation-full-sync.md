# 全域局域网同步验收

2026-10-11，实现基准：`6b2e899`。非 AI 核心对象已接入 Windows / Android 局域网自动同步。服务为本机 HTTPS 开发部署；云账号登录与物理手机验收尚未完成。本文按测试证据区分通过与待验证，AI 功能继续暂停。

## 同步范围

统一实体协议覆盖收件箱及澄清关联、任务、项目、分区、每日安排、记录、习惯及打卡、重复规则和发生项、回顾、保存视图、工作空间设置、策略、决策和专注记录。桌面独有的依赖、排序、规则修订、回收站和活动历史以关联实体保留，手机编辑必须保留未知字段。

桌面运行期间自动同步；Android 前台每 5 秒，以及恢复前台/网络后同步。Android 被系统停止时不会承诺持续后台工作。

## 安全迁移和冲突

- 使用原有本机 DPAPI / Android Keystore 配对和独立 CA 的 HTTPS 连接。
- 新迁移附加同步表，不清空业务数据库。旧收件箱影子作为升级基线，未发送原文保留到新协议确认。
- 同一业务命令的关联对象作为一个原子批次；远端版本与本地编辑版本分开。
- 命令持久化后固定操作 ID 和参数，响应丢失可重试；批次及游标同事务落盘。
- 不同字段基于真实历史版本合并；同字段冲突保留双方并校验解决时的基线。
- 服务实例变化时先取得一致快照，保留未发送的本机修改，再重新建立影子与游标。

桌面附加 migration 0021/0022，手机 SQLite 附加 v5 迁移。旧业务主键、标签与每日安排引用由别名映射保护；工作空间设置、习惯同日记录及重复发生项采用稳定身份。原始确定时刻、时区和估时不因手机只编辑标题而被日期显示值覆盖；手机保留尚未提供编辑入口的桌面字段。保存视图保留原筛选语义，结构化周回顾按字段同步并生成一致正文。

测试脚本：`scripts/lan-full-sync.mjs`、`scripts/lan-full-faults.mjs`、`scripts/lan-full-domains.mjs`、`scripts/lan-full-views-drafts.mjs`。结果及截图保存在 [验收证据目录](evidence/lan-full-sync/)。测试通过真实 App 页面和应用公开命令修改数据，没有通过直接后端写入替代客户端接入。桌面主验收使用独立数据目录，Android 保留已安装 App 的数据库。

Android 生命周期复验由共享 `scripts/android-sync-test.mjs` 强制停止并重新启动原生 App，保留数据库及 WAL；不使用调试页面 reload 代替系统生命周期。编辑保护同时检查页面草稿、原生版本变化和公开保存命令的旧版本拒绝。

完整 Rust 回归 135 项通过，Vitest 全套 29 个文件、132 项通过；保存视图包含工作空间时区跨午夜的日期边界回归。正常桌面数据库执行 0021/0022 后，原有 16 个任务、1 个项目和 12 个收集项的核心属性及收集项物理创建时刻均保留，证据 `normal-upgrade.json`。原有三级任务树已在 Android 真实 UI 展开，证据 `original-tree.json`；同步保留任意层级并拒绝父子环，手机移动、删除与恢复处理完整子树。

升级遇到的 4 个旧收集项仅存在服务接收时刻与本机创建时刻元数据差异。逐项核对业务字段及删除状态一致后，通过公开冲突解决命令明确采用协议规范元数据，同时保留本机原始物理创建时刻。正常桌面最终 online、待发 0、冲突 0、实体游标 123，证据 `metadata-reconciliation.json`；没有用直接数据库修改清除冲突。

最终安装版本重新执行视图/草稿五项及故障三项，全部通过。服务重启后再次核对原始数据、原有任务树及两端状态，桌面游标推进至 162、待发和冲突为 0；Android 自动同步正常，无拒绝批次。证据 `final-state.json`。当前桌面运行文件为忽略目录 `.tools/praxis-desktop-sync/Praxis.exe`，Android 调试 APK 已覆盖安装；两端凭据及业务数据库保留。

Standards 与 Spec 由独立子 agent 审查，发现的问题已修复并补回归，最终没有剩余阻塞项。修复包含默认字段映射、旧实体创建时刻、稳定身份别名、原有多级子任务、结构化回顾标题、视图日期时区及编辑草稿保护。未验证的规模性能属于 T30 后续验收，未据此宣称达到性能目标。

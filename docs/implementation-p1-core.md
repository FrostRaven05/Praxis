## 数据与兼容决策

新增 0011 迁移，在升级前沿用一致性备份。新增工作空间设置、标签/任务标签、分区、每日结果和迁移报告；任务新增 typed time、P1–P4、等待信息、分区和完成时间；项目新增取消标记和独立归档时间。SQLite 整库备份自动覆盖所有新增表、事件与 outbox。

1. 新 `plan` 初始取旧每日安排中最新有效的执行日期；全部旧安排、重点、执行事实仍保留。甘特窗口保持独立，不映射为真实期限。旧入口显式安排会更新新计划；完成任务不会改写计划。新入口编辑计划不重写历史安排。
2. 旧截止迁为确定时刻；日期型截止只存在 typed time 中，不伪造成午夜 UTC。确定时刻输入明确标注 UTC，旁边显示工作空间时区结果；保存规范化 UTC，并保留显示时区。时区变更列出所有已有确定时刻的前后显示，日期文字、每日结果日期和完成历史不重算。
3. 新优先级默认 P4，旧重要标记独立保留并显示，不猜测其优先级。等待用独立标记表达，底层旧状态兼容保存为 todo；对外新快照、项目任务和详情显示 waiting。blocked 保持阻塞语义，切换与终结同步清理等待。不能选等待任务作下一步。
4. 沿用 T01 的多级树兼容原则，不限制或压平旧数据；新项目组织入口默认展示顶层已完成/未完成/已取消，同时明确显示原叶子进度。保留原同级排序、子树移动和甘特能力。跨项目移动遇到已有甘特依赖时要求先解除依赖，不静默删关系。
5. 取消项目在兼容存储中使用 completed 加独立 canceled 标记，对外显示已取消。归档为独立 `archived_at`，侧栏隐藏已归档项目，设置和项目组织入口仍能找到。旧归档有未完成任务时迁为暂停并恢复可见；无未完成任务时迁为已完成并保留归档标记（旧库没有归档时间，以创建时间作为兼容标记，报告明确说明）。
6. 新命令、事件与 outbox 单事务；重试复用操作 ID。移动/父子状态变更对预览时任务 ID/版本集合校验，项目终结校验项目和计划版本；过期预览拒绝，不覆盖后续修改。项目和父项终态规则也有数据库约束，旧入口不能绕过。

这些为用户要求实施 T08–T14 时采用的兼容方案，不声称新版 SPEC 中“一层子任务”已原样替换旧版多级模型。新旧验收冲突已记录：两项原生生命周期测试不再允许把未完成项目直接完成/归档，改为验证暂停保留/移除安排；新测试覆盖严格终结、归档和重开规则。

# Android 手机端参考布局与非 AI 本地功能

日期：2026-10-11。基准提交：37f70dda71dff2e70bbe6bf20e30449ebe43de54。

## 交付范围

按用户参考图实现顶部周历、实际完成趋势、可展开的任务与子任务、悬浮新增、底部清单/日历/项目/统计/我的。共用 DESIGN.md 的主题与深浅色变量，默认冰蓝色；“我的 → 主题颜色”提供冰蓝、珊瑚红、鼠尾草绿、雾紫及自定义颜色，立即生效并在本机保留选择。强调文字、项目图标、任务勾选轮廓使用统一的较深主题色，填充保持柔和，扩展页面不再固定使用绿色。Capacitor 使用独立手机入口。

三个实现子 Agent 分别负责本地数据、主界面、扩展页面；主 Agent 整合收件箱澄清/撤销、原生文件导出、连接恢复和模拟器验证。两个独立子 Agent 分别进行需求与规范审查。

- 任务、项目、父子关系、分区、计划/期限/跟进日期、优先级、标签、等待说明、恢复卡、下一步、每日结果/重点/收尾。
- 原文收集、编辑、澄清预览、任务或记录输出、安全撤销；有后续修改或引用时保留输出。
- 习惯与打卡、重复任务与未来规则预览、记录关联、策略/决策文本模板、手动回顾、搜索与保存筛选、回收站、统计和专注计时。
- 手机工作空间 JSON 导出、完整格式和引用校验、导入新空间及切回原空间；系统文件分享选择器由用户自行选择保存目的地，不自动发送。

## 数据与兼容

手机 SQLite v3 使用附加迁移保留旧 tasks、daily_plan_items、captures、历史与待发队列；旧对象迁入本机工作空间，未清库。新实体、版本和命令日志同事务提交，未知提交重试使用原操作编号。工作空间实体以 workspace_id 隔离；手机导出包含实体和手机历史，导入保留原空间。

原生 WebView 重新加载可能保留 SQLite 原生连接，因此开库前核对连接注册状态，再创建或取得连接。此修复在真实插件运行中验证。

手机实体格式目前与桌面存储模式不同，尚无跨端转换和同步实现。本地命令日志数量不能解释成已同步数量。本次没有创建云服务、登录账号或发送项目内容；AI 保持暂停。

## 已完成行为

- React 录入调用共享 CaptureToday；日期使用用户 IANA 时区，UTC 午夜不会误排日期。
- Rust/SQLx 在同一连接事务内保存 Task、DailyPlanItem、DomainEvent、SyncOutbox。
- 空标题拒绝；持久层复核 UUID、时区、日期与事件时间；失败返回可重试提示。
- 同一未确认操作重试沿用 operation_id，已提交操作重放不重复创建记录。
- 本地身份与设备 ID 随数据库持久化；恢复时保留历史与 outbox。
- 今日页面从 SQLite 查询，不另存可写任务全集；浏览器预览不能保存任务。

## TDD 记录

- 日期跨 UTC 日：先因模块缺失失败，最小实现后通过。
- 空标题：先因用例缺失失败，加入标题校验后通过。
- 标题录入并按本地日期读取：先因未实现保存失败，接通存储契约后通过。
- 模糊保存结果重试：先得到重复任务失败，保存待确认操作身份后通过。
- 真实 SQLite 关闭重开：先因存储模块缺失失败，迁移与事务实现后通过。
- 已提交命令重放：先因唯一约束失败，事务内识别原操作后通过。
- 中途约束失败、非法输入和身份复用：通过公开存储接口验证，无需检查内部连接状态。

## 原生验收方式

使用真实 Windows Tauri 调试程序，通过 WebView2 CDP 操作输入框、按钮和任务详情。采用 Playwright 官方描述的 WebView2 连接方式，不启动浏览器版替身。数据保存在独立测试目录，外部 HTTP(S) 请求被阻断；没有修改系统网络适配器。

已实际验证空标题错误、中文录入、回车提交、任务详情、强制结束进程后重开及两条任务恢复。截图和机器结果位于 evidence/ticket-01。待最终回归后记录完整结果。

原生交互插件初始化连续两次失败，错误为 trusted Node process exited unexpectedly；因此改用应用自身 WebView2 测试通道。没有将插件失败当作通过。

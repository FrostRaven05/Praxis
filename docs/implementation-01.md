- 空标题拒绝；持久层复核 UUID、时区、日期与事件时间；失败返回可重试提示。
- 同一未确认操作重试沿用 operation_id，已提交操作重放不重复创建记录。
- 本地身份与设备 ID 随数据库持久化；恢复时保留历史与 outbox。
- 今日页面从 SQLite 查询，不另存可写任务全集；浏览器预览不能保存任务。

已实际验证空标题错误、中文录入、回车提交、任务详情、强制结束进程后重开及两条任务恢复。截图和机器结果位于 evidence/ticket-01。最终回归也通过数据库不可用时的错误与草稿保留、跨午夜重试后的原日结果展示和返回今日、脱敏诊断记录。

原生交互插件初始化连续两次失败，错误为 trusted Node process exited unexpectedly；因此改用应用自身 WebView2 测试通道。没有将插件失败当作通过。

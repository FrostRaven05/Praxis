# D07 桌面项目工作区验收

本轮实现原 Tickets 13–18 的桌面本地流程。任务、看板和甘特图共用任务身份与版本，不创建另一份任务副本。

## 操作入口

- 项目 → 管理项目状态：草稿、进行中、暂停、完成、归档及重点标记；全部、重点、归档列表筛选。
- 暂停／归档时明确选择保留安排，或移出今天及以后未完成的安排。过去的安排及完成事实保留，恢复项目不会自动恢复移出的安排。
- 任务视图：上移／下移调整同级顺序；移动层级移动整棵子树或提升到根层级。父子保持同项目，不能移入自身或后代。目标父项已有安排须确认转汇总。
- 看板：待办、进行中、阻塞、已完成四列，拖动卡片标题区域或使用状态菜单；阻塞／取消填写原因。取消项单独查看，支持恢复原状态。
- 看板和今日共用完成事务；无安排任务完成后进入实际完成日。完成及开始检查前置任务，撤销保留原事实及撤销时间。
- 甘特图：42 日可滚动时间轴、前后翻页、今日线、未排期入口、叶子日期及前置依赖编辑、依赖连线、父项汇总条。拖动任务条生成日期调整预览。
- 延后前置任务会生成保持工期的基础顺延方案；确认批量提交或取消。每日安排不自动移动，超出窗口显示提示。撤销上次排期使用计划版本检查，任何并发任务修改使旧预览失效。

## 数据与规则

迁移 0008 保留原任务、计划、执行事实、历史与 outbox；新增生命周期、移出标记、排期和依赖图。默认估时只带入新安排，恢复旧安排保留其独立估时。项目完成不批量伪造任务完成。项目资格规则只允许进行中项目参与后续推荐。

同项目依赖、自依赖、循环及汇总项依赖受事务校验与数据库约束保护。排序、移动及排期原子提交；状态命令使用任务版本，排期与层级命令使用项目计划版本。共享 TypeScript 做规则校验，Rust 在写事务中复核最新状态。

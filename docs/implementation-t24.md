## 前置通过后的实现切片

以下为同一 T24 内的交付步骤，不是已经完成的功能。

1. **确定共享存储边界与夹具。** 在 application 层明确项目快照、任务详情、恢复卡和每日记录接口，包含版本、操作 ID 与结果；按现有桌面行为建立完成/撤销、下一步清除、日期独立、父子约束与错误重试夹具。两端分别执行同一夹具，避免移动端重新解释规则。
2. **版本化升级本机数据库。** 保留已有收集项、旧任务、每日安排与队列，新增项目/恢复卡/分区/日期/每日记录所需模型。测试旧库升级、失败回滚、重开读取及外键；不要把桌面版本号直接当移动版本号。
3. **项目读取与恢复卡。** 先交付项目列表到项目详情到恢复卡的逐页入口；保存需检查版本，实体、事件和队列同事务提交。失败保持草稿并允许同操作 ID 重试，成功后原生重读确认。
4. **任务编辑、状态与安排。** 接通平台选择的存储接口后开放按钮；支持独立计划/截止/跟进时间和工作空间时区，复用状态、下一步、父子与终态约束。完成及撤销需维持执行记录和原安排，不以再次新增任务实现撤销。
5. **四入口与离线反馈。** 实现底部今日/收件箱/项目/更多，任务详情独立页面，返回时保护未保存草稿。纯本地模式明确仅有本机数据；同步接入后以持久化范围元数据表示已下载和未下载，不从空查询猜测资料不存在。
6. **实际 Android 验收。** 完成以下清单后才关闭 T24；若只通过适配器单测，状态仍为部分实现、待真机验证。

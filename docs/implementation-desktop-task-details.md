## 行为

收件箱、项目任务列表和今日任务详情均提供「编辑详情」，共用同一任务记录和编辑器。可编辑标题、备注、完成标准、任务重要度、截止时间及预估工作量。

无日期任务保存后仍没有安排。任务重要度在列表显示「重要」，独立于每日重点；截止时间独立于安排日期，以 UTC 时间戳和设置时 IANA 时区保存，表单按当前本地时间显示。截止时间不会自动注册提醒。

预估工作量为 1–1440 分钟，留空为未知；加入日期时作为新安排的预计投入。修改任务预估不会覆盖已有每日估时。编辑已完成任务不修改完成事实、完成日期和原安排。

模态编辑器持有打开时的版本；后台刷新不覆盖草稿，连续保存使用已确认版本。失败保留输入，过期版本拒绝覆盖；可以显式重新加载放弃当前草稿。弹窗打开时屏蔽页面导航快捷键，关闭前等待父视图刷新，避免下一次输入被重建编辑器覆盖。

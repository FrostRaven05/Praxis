# T21：暂停和规则版本历史

沿用 T20 的习惯、规则区间和事件表，无需新增迁移。新增 `HabitAction::Rule`，公开命令与查询接口保持不变。

习惯详情提供暂停、恢复和频率编辑，用户选择工作空间时区的次日或下周一生效。先显示具体日期、频率与历史保留说明，再显式确认。本地存储层检查确认标志、时区、习惯版本、生效边界和合法频率。关闭旧区间、写入新规则、更新版本、记录事件及发送队列在一个事务完成，重复操作 ID 幂等。

规则历史列出全部版本和左闭右开区间。已安排但尚未生效的规则会显示生效日期，待其生效后才能再次调整，避免替换待生效版本。暂停期间没有执行要求；恢复使用新的规则版本。单日跳过仍是独立记录。

周统计依各日有效规则计算，暂停天数不进入每日分母。新建、暂停和跨规则周标记不完整周；旧记录的日期、时区和规则版本不会因规则变更重新写入。跨规则周每周目标仅供参考，不评价完整周达标。

验证：TypeScript 类型检查通过；习惯原生测试 5/5 通过（含新增规则测试）。新增规则定向测试覆盖暂停恢复、次日/下周生效、预览确认、拒绝过去日期和待生效重复修改、乐观版本冲突、幂等，以及历史统计和记录保留。使用 cargo test --offline --locked --test habits 完成定向验证。桌面交互由主集成统一验证，本文件不代替真机或同步验收。

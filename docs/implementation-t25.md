先在真实协议上增加项目与任务命令及变更覆盖，再接入两端持久队列、确认、基线和原子拉取；接着覆盖分区、标签、恢复卡、每日安排和所有引用副作用。每个切片用真实服务器事务测试验证回滚与幂等，再进入 Windows/Android 集成。

# 09 — 在安装端验证任务提醒与文件导出

**What to build:** 用户在桌面和手机为一条本地任务设置测试提醒，并将其导出为本地文件。

**Blocked by:** 02 — 在移动端离线录入同样的任务。

**Status:** draft — awaiting breakdown approval

**Milestone:** M0

**依据:** 技术路线 §7、§8 M0。

- [ ] 以单条任务演示移动本地通知和桌面安装包通知；关闭权限后主流程仍可用。
- [ ] 验证移动暂停/返回前台及桌面运行、托盘、完整退出情况下的行为，记录能力边界，不把 JavaScript 定时器当后台保障。
- [ ] 导出本地最小 JSON 文件，桌面保存、移动分享均可操作，取消和失败有明确反馈。
- [ ] 本 Ticket 只交付原生适配的窄切片，完整提醒规则和全量导出由后续 Tickets 扩展。
- [ ] 记录测试设备、安装方式、输入法与滚动检查；M0 在 01–09 全部验收后放行。

**完成边界:** 交付本行为所需的数据约束、应用用例、存储/同步或 API、可操作界面及验证证据；已有能力复用。安装端新增业务行为须验证离线持久化、重连收敛和失败提示。纯本地原型阶段不虚构已接通云端；API 从登录同步切片起持续覆盖。后续功能不塞入本 Ticket。

**演示证据:** 提供本 Ticket 的用户操作步骤、验证命令或设备记录、实际结果和未验证环境；不得把计划中的测试勾为已完成。

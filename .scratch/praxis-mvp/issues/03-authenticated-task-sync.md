# 03 — 登录后让双端看到同一任务

**What to build:** 同一用户登录桌面与手机后，一端新增的任务和每日安排能出现在另一端。

**Blocked by:** 02 — 在移动端离线录入同样的任务。

**Status:** ready-for-agent

**Milestone:** M0

**依据:** 技术路线 §4、§5.1、§7；Spec §9。

- [ ] 接通邮箱登录、令牌校验、Fastify 命令与增量拉取以及 PostgreSQL 存储；云端业务写入只走命令服务。
- [ ] 服务端身份来自令牌；越权读写和跨用户引用被拒绝，账号切换隔离本地数据库；安装端令牌使用安全存储。
- [ ] 任务及安排的 operation_id 幂等生效，业务数据、结果和 ChangeLog 在同一事务提交。
- [ ] 用户级锁和事务内序列保证提交顺序与拉取游标一致；客户端落地数据与游标原子提交。
- [ ] 前台/重连/手动刷新触发同步；界面显示待同步、成功或失败，令牌过期暂停上传并保留队列。
- [ ] 测试响应丢失后重试、跨账号访问和双设备收敛；使用可复现测试环境，不要求本 Ticket 发布生产服务。

**完成边界:** 交付本行为所需的数据约束、应用用例、存储/同步或 API、可操作界面及验证证据；已有能力复用。安装端新增业务行为须验证离线持久化、重连收敛和失败提示。纯本地原型阶段不虚构已接通云端；API 从登录同步切片起持续覆盖。后续功能不塞入本 Ticket。

**演示证据:** 提供本 Ticket 的用户操作步骤、验证命令或设备记录、实际结果和未验证环境；不得把计划中的测试勾为已完成。

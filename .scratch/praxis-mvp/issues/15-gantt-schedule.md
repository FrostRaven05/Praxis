# 15 — 在甘特图查看和编辑日粒度排期

**What to build:** 用户看到项目任务条、今日线和未排期列表，并在桌面及手机修改计划日期。

**Blocked by:** 12 — 创建项目并拆出可执行任务。

**Status:** ready-for-agent

**Milestone:** M2

**依据:** Spec §6.5、§7.4；技术路线 §6。

- [ ] 采用 React + SVG/CSS 展示按日任务条、今日线、排序与未排期列表，不另存任务副本。
- [ ] 开始/结束日校验并同事务更新，更新计划版本；无日期任务可手动加入今日。
- [ ] 桌面可调整任务条日期，移动横向浏览并通过表单编辑；列表和时间轴纵向同步。
- [ ] 排期修改不改执行日期或截止时间；提示已有安排超出新窗口。
- [ ] 测试日期组冲突、未排期到已排期、离线编辑及另一端显示一致；依赖连线由下一 Ticket 接入。

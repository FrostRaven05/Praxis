# 28 — 导出完整项目数据及回顾历史

**What to build:** 用户从设置导出完整数据包，包含项目执行和回顾历史，而非只有当前任务列表。

**Blocked by:** 09 — 在安装端验证任务提醒与文件导出；26 — 事实修正后提示更新回顾版本。

**Status:** ready-for-agent

**Milestone:** M3

**依据:** Spec §6.7、§9；技术路线 §6。

- [ ] JSON 带 schema_version，包含项目、任务、排期、依赖、每日安排、执行记录、总结/周报及其版本和关联。
- [ ] 回顾同时导出 Markdown；保留稳定标识、时区与历史，使跨日事实可核对。
- [ ] 读取一致快照，说明是否含未同步操作和未解决冲突；不导出令牌或管理密钥。
- [ ] 桌面文件保存和移动分享可用，用户取消不报错，失败不宣称成功。
- [ ] 用已知样本核对数量、引用完整性、撤销事实、旧版本及中文内容；本 Ticket 不引入产品级导入功能。

**完成边界:** 交付本行为所需的数据约束、应用用例、存储/同步或 API、可操作界面及验证证据；已有能力复用。安装端新增业务行为须验证离线持久化、重连收敛和失败提示。纯本地原型阶段不虚构已接通云端；API 从登录同步切片起持续覆盖。后续功能不塞入本 Ticket。

**演示证据:** 提供本 Ticket 的用户操作步骤、验证命令或设备记录、实际结果和未验证环境；不得把计划中的测试勾为已完成。

# 27 — 设置任务、晚间总结和周报提醒

**What to build:** 用户选择提醒时间与设备，在移动端收到本地提醒并打开相应任务或回顾。

**Blocked by:** 09 — 在安装端验证任务提醒与文件导出；25 — 基于事实生成、编辑和导出周报。

**Status:** ready-for-agent

**Milestone:** M3

**依据:** Spec §6.6–6.7、§9；技术路线 §7。

- [ ] 提供任务、晚间总结和周报提醒设置，建议不逐条推送；通知点击打开对应对象。
- [ ] 保存、改期、完成、同步及时区变化后核对提醒 ID，撤销旧调度并更新。
- [ ] 移动端使用原生本地调度；权限拒绝、精确提醒受限有状态与恢复入口，主流程可继续。
- [ ] 桌面运行/托盘和完整退出行为按 M0 结论实现并说明；若首发范围要求退出仍提醒，补齐 OS 适配并真机验证后才放行。
- [ ] 可指定默认提醒设备；离线多设备不承诺严格一次通知，测试重启、权限变更和重复调度。

**完成边界:** 交付本行为所需的数据约束、应用用例、存储/同步或 API、可操作界面及验证证据；已有能力复用。安装端新增业务行为须验证离线持久化、重连收敛和失败提示。纯本地原型阶段不虚构已接通云端；API 从登录同步切片起持续覆盖。后续功能不塞入本 Ticket。

**演示证据:** 提供本 Ticket 的用户操作步骤、验证命令或设备记录、实际结果和未验证环境；不得把计划中的测试勾为已完成。

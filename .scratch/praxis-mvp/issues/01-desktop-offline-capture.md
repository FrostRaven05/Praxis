# 01 — 桌面离线录入并保留临时任务

**What to build:** 用户在桌面应用只输入标题即可保存任务，关闭应用后再次打开仍能看到。

**Blocked by:** None — can start immediately。

**Status:** ready-for-agent

**Milestone:** M0

**依据:** 技术路线 §1、§3–5、§8 M0；Spec §6.3、§8.1(4)。

- [ ] 交付可启动的 Tauri + React 桌面应用及最小今日入口；临时任务带 UUID、录入来源和用户日历日期，允许项目为空。
- [ ] 通过共享用例和原子存储接口将任务、当日安排、历史及 outbox 同事务保存；Rust/SQLx 持有事务连接，不由 UI 直接写 SQL。
- [ ] SQLite 查询驱动界面；空标题拒绝，失败明确提示；断网及杀进程重启后记录仍在。
- [ ] 随本切片建立 pnpm 工程、严格 TypeScript、依赖锁定及最小验证入口；只建本行为所需结构，不预建全部模块。
- [ ] 验证事务中途失败无半份数据、日期时区跨午夜、SQLite 初始迁移；录屏或记录实际桌面操作。

**完成边界:** 交付本行为所需的数据约束、应用用例、存储/同步或 API、可操作界面及验证证据；已有能力复用。安装端新增业务行为须验证离线持久化、重连收敛和失败提示。纯本地原型阶段不虚构已接通云端；API 从登录同步切片起持续覆盖。后续功能不塞入本 Ticket。

**演示证据:** 提供本 Ticket 的用户操作步骤、验证命令或设备记录、实际结果和未验证环境；不得把计划中的测试勾为已完成。

# 12 — 创建项目并拆出可执行任务

**What to build:** 用户写出项目预期结果，拆成任务并将原任务加入今日，也能把临时事项归入项目。

**Blocked by:** 05 — 把同一任务安排到某日且双端去重；07 — 完成任务并撤销误完成。

**Status:** ready-for-agent

**Milestone:** M1

**依据:** Spec §5、§6.3、§6.5；技术路线 §4。

- [ ] 项目可设置名称、预期结果、目标日期和优先级；任务支持标题、备注、完成标准、估时、重要度、截止时间及排序。
- [ ] 项目任务列表和今日共用任务 ID；加入今日不复制任务，编辑和完成跨视图、跨端同步。
- [ ] 临时任务可归入已有项目；可转为新项目并保留原事项关联与执行历史，明确原任务保留为关联行动。
- [ ] 项目与任务变更记录可供后续回顾引用；服务端拒绝跨用户项目引用。
- [ ] 双端可新建及编辑，桌面支持批量录入；验证无日期、无估时任务与离线创建项目后连续添加任务。

**完成边界:** 交付本行为所需的数据约束、应用用例、存储/同步或 API、可操作界面及验证证据；已有能力复用。安装端新增业务行为须验证离线持久化、重连收敛和失败提示。纯本地原型阶段不虚构已接通云端；API 从登录同步切片起持续覆盖。后续功能不塞入本 Ticket。

**演示证据:** 提供本 Ticket 的用户操作步骤、验证命令或设备记录、实际结果和未验证环境；不得把计划中的测试勾为已完成。
